# 01. Project Overview & Repository Structure

## Project Purpose & Overview

The `demo-repo` repository is an organizational template and demonstration repository under the `VoidAlgo` organization. As declared in its root `README.md`, its purpose is to demonstrate GitHub features with the least amount of noise. 

The repository serves as a minimal boilerplate that demonstrates:
1. Static HTML hosting / rendering capability via a basic `index.html`.
2. Automated workflow execution using GitHub Actions for issue/PR assignment (`auto-assign.yml`).
3. Automated HTML validation and link proofing via GitHub Actions (`proof-html.yml`).
4. NPM package dependency specification linking GitHub's design system (`@primer/css`).

## Repository Structure

The complete file tree of the repository is as follows:

```
demo-repo/
├── .github/
│   └── workflows/
│       ├── auto-assign.yml    # GitHub Actions workflow for auto-assigning issues & PRs
│       └── proof-html.yml     # GitHub Actions workflow for validating HTML files
├── index.html                 # Minimal root HTML entrypoint
├── package.json               # NPM package manifest declaring dependencies and metadata
├── README.md                  # Root introductory readme
└── thedocs/                   # Comprehensive repository documentation
    ├── README.md
    ├── 01_project_overview.md
    ├── 02_architecture_and_workflows.md
    ├── 03_configuration_and_dependencies.md
    ├── 04_testing_and_quality.md
    └── 05_technical_debt_and_limitations.md
```

## Important Files & Directories

- `index.html`: Contains a single `<h1>` heading: `<h1>Welcome to the website generated by my demo repository</h1>`. It acts as a static web artifact.
- `package.json`: Declares package metadata (`"name": "demo-repo"`, `"version": "0.2.0"`, `"license": "MIT"`) and a single dependency on `@primer/css: 17.0.1`.
- `.github/workflows/auto-assign.yml`: Automates triage by assigning new issues and pull requests to `Makilesh`.
- `.github/workflows/proof-html.yml`: Executes HTML validation using the `anishathalye/proof-html@v1.1.0` action upon push and manual workflow dispatch.
- `README.md`: High-level description summarizing the contents.
